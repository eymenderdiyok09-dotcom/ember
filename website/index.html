Download

macOS

Universal · Apple Silicon & Intel · macOS 11+ · 4.4 MB

Download for macOS
  1. Open Ember_0.1.0_universal.dmg and drag Ember into Applications.
  2. Open Ember. If macOS says it can't check it for malware, open System Settings → Privacy & Security, scroll down and click Open Anyway.
  3. If macOS says Ember “is damaged”, run this once in Terminal, then open it again: xattr -dr com.apple.quarantine /Applications/Ember.app

Windows

Windows 10 & 11 · portable · about 2 MB

Download for Windows ARM64 version (Snapdragon, Surface Pro X)
  1. Right-click the downloaded .zip → Extract All, and move the folder wherever you like.
  2. Open Ember.exe. Keep any files next to it in the same folder.
  3. If you see “Windows protected your PC”, click More info → Run anyway.

On Windows, Ember can also start Bedrock Edition if you have it installed.

Questions

Is Ember free?

Yes. No ads, no accounts, no tracking.

Why does my computer warn me when I open it?

Ember isn't code-signed yet — that needs a paid Apple and Windows developer certificate. The steps above show how to open it anyway.

Can I play on online servers?

Online-mode servers and Realms need a Microsoft account that owns Minecraft: Java Edition. Ember's Microsoft sign-in is built and waiting for approval from Mojang; until then, Ember plays in offline mode (singleplayer and offline-mode servers).

Does FPS Boost touch my mods or worlds?

No. FPS Boost runs from its own folder (ember/instances) and links to your real worlds, resource packs, shader packs and screenshots. Your own mods folder is never changed.

Where does Ember put game files?

In the standard Minecraft folder — ~/Library/Application Support/minecraft on macOS and %APPDATA%\.minecraft on Windows — so it works alongside the official launcher.
