Code signing policy and privacy

How Ember's downloads are signed, who can sign them, and exactly what Ember talks to over the network.

Code signing

macOS: Ember for macOS is signed with an Apple Developer ID certificate belonging to Eymen Derdiyok and notarized by Apple.

Windows: Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Windows signing through SignPath Foundation has been applied for. Until it is approved, Windows builds are unsigned and Windows shows a warning the first time you open Ember.

Signed Windows binaries are built by GitHub Actions directly from the source code in the public repository. Every signing request is approved by hand.

Updates: Ember (0.5.0 and newer) only installs updates whose manifest is signed with the project's Ed25519 release key and whose download matches the SHA-256 hash in that manifest.

Team roles

  • Committers and reviewers: members of the repository — currently Eymen Derdiyok (@eymenderdiyok09-dotcom).
  • Approvers: Eymen Derdiyok (@eymenderdiyok09-dotcom), owner of the repository.

Contributions from people outside the team are reviewed before they are merged. All team members use multi-factor authentication for GitHub and SignPath.

Privacy policy

Ember has no accounts of its own, no ads, no analytics and no telemetry. It does not collect, store or send personal data to the Ember project.

To work, Ember connects only to these services, and only for the purpose listed:

  • Mojang (piston-meta.mojang.com, piston-data.mojang.com, launchermeta.mojang.com, resources.download.minecraft.net, libraries.minecraft.net) — the list of Minecraft versions, the game files and Java runtimes.
  • Maven Central (repo1.maven.org) — a newer version of one game library (JNA) that older Minecraft versions need on recent macOS.
  • Fabric, Forge and NeoForge (meta.fabricmc.net, maven.fabricmc.net, files.minecraftforge.net, maven.minecraftforge.net, maven.neoforged.net) — mod loaders, when you pick one.
  • Modrinth (api.modrinth.com, cdn.modrinth.com) — the FPS Boost mods and the shader pack, when those are switched on.
  • GitHub (github.com) — checking for and downloading Ember updates when Ember opens.
  • Ely.by (authserver.ely.by, skinsystem.ely.by, ely.by) and authlib-injector (authlib-injector.yushi.moe) — only if you sign in with Ely.by or use a custom offline skin. Your Ely.by password is sent only to Ely.by and is never stored; Ember keeps a login token in your system's keychain.
  • Microsoft and Xbox (login.microsoftonline.com, xboxlive.com, minecraftservices.com) — only if you sign in with Microsoft.

These services see your IP address like any website you visit; their own privacy policies apply. Custom offline skins are served to the game by a small server that runs on your own computer (127.0.0.1) and is not reachable from the network.

This website is hosted on GitHub Pages behind Cloudflare, loads fonts from Google Fonts, and reads the public Minecraft version list from Mojang to show the version count. It sets no cookies of its own; your language choice is remembered in your browser only.
