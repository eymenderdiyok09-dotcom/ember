Features

Every version

Any release or snapshot, back to the Alpha days of 2010. Ember downloads it straight from Mojang — no official launcher needed.

FPS Boost

On by default. Sodium, Lithium, FerriteCore and more in their own folder, plus Java tuned for smooth frames. Your worlds stay shared.

Fabric, Forge, NeoForge

Install any mod loader in one click. Ember picks the latest stable build for your game version.

No Java setup

Each version gets the exact Java runtime it needs, downloaded and checked automatically.

Offline & Microsoft

Play offline with any name. Microsoft sign-in for online servers is built in and coming soon.

Tiny and native

About 4 MB, opens instantly, and every downloaded file is checksum-verified.

FAQ

Is it free?

Yes. No ads, no accounts, no tracking — and the code is open on GitHub.

Is it safe?

The macOS app is signed and notarized by Apple. Game files come straight from Mojang, mods from Modrinth, and every file is checked against its official checksum. Windows builds aren't code-signed yet, so Windows shows a warning the first time.

Can I install mods?

Yes. Pick a Fabric, Forge or NeoForge version and put your mods in the mods folder of your Minecraft directory.

Does FPS Boost touch my mods or worlds?

No. FPS Boost runs from its own folder (ember/instances) and links to your real worlds, resource packs, shader packs and screenshots. Your own mods folder is never changed.

Can I play on online servers?

Online-mode servers and Realms need a Microsoft account that owns Minecraft: Java Edition. Ember's Microsoft sign-in is built and waiting for approval from Mojang; until then, Ember plays in offline mode.

Minecraft doesn't start. What should I do?

Try turning FPS Boost off, or lowering the memory slider. If it still won't start, open an issue on GitHub and attach logs/mc-launcher-output.log from your Minecraft folder.
